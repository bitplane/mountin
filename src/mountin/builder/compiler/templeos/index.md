# TempleOS compiler toolboxes

Toolboxes for rebuilding TempleOS from Terry A. Davis's HolyC source. A
source-built AIWNIOS runtime supplies the initial HolyC execution environment;
TempleOS then compiles its own compiler and kernel as part of its original
distribution procedure.
