# AIWNIOS

BSD-licensed HolyC compiler and runtime used to bootstrap TempleOS tooling
without importing a precompiled TempleOS compiler. This snapshot includes the
upstream bootable-RedSea-image work and the compiler, assembler, host filesystem
and TempleOS changes maintained for Mountin.
